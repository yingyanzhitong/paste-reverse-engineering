## 沿三条真实消费者链收敛

| 消费者链 | 保留现有实现，集中核对剩余差异 |
| --- | --- |
| 搜索/设置入口 → 输入模型 → provider/索引 → 菜单与结果 | 建议整 query 分支、完整列表/Scroller 工厂和焦点/键盘边界；设置各页的原布局、控件、默认值和资源文案。JSON provider 与原实体持久名称、可空来源、关系及排序仍有差异。 |
| 捕获/多选/Pinboard/历史 → 仓库事务 → 剪贴板恢复 → Undo/通知/Stack 消费 | 同一事务链统一核查复制/移动、删除保留、时间戳、失败与撤销；写入剪贴板成功和目标应用实际粘贴成功应分别处理。现有 JSON CRUD、writer 和队列无需重新实现。 |
| 卡片 → 原生预览/Header → 内容编辑 → 持久化/metadata | 补证文件复制时尺寸、原 VM metadata 来源、写入失败后的编辑状态、Header 可用性与设置行为。保留已接图片/颜色/链接编辑，完整 owner/lazy/异步任务生命周期仍为 partial。 |

## 真实缺失与未审项

具体未决包括：原复制/粘贴音效及默认开关差异、恢复通知到 ClosedState/持久 token 的完整链、Stack完整路由和发送边界（原版同样没有目标接受回执）、OSD 可选 action，以及完整日志文件列表的产品消费者。当前日志 URL、确认后重启、多选混合写入和共享 Undo 已有消费者，不能继续按缺失重复实现。

原本地 Sentry Scope/Breadcrumb 的快照、环形缓存及 observer 副作用尚未接入；它们不能因排除联网就整体算完成，本次保留缺口。快捷键 CodingKey 默认描述的类型名，以及剩余编译器生成函数，仍有未审地址；不能从系统组件或 Swift 已生成类似代码推定逐地址等价。完整 actor 析构、原 CoreData 身份/事务、持久化图标与 helper 启动差异继续单列。EXIF raw方向值已证原样传递，旧回退.up缺口为误判，已撤回，完整异步ABI及跨actor诊断仍待解决。

后续每个行为单元只做一次“入口 → 输入/输出 → 失败副作用 → 最终消费者”对照：已有路径复用，仅将证实的差异转为修改项；重叠仓库/预览问题合并处理。最终统一冻结源码、编译并列出保留差异；逐地址迁移数、静态审阅结果与功能回归结果分别记录。

本轮修正应用名筛选/索引值、建议菜单键盘优先级和选择/冷却/接受清理、行样式及标题对齐；更正图片缩放、棋盘背景、诊断重启和日志 URL 等已实现却被旧报告列缺的项目。完整72项及源码绑定见 [集中核对明细](fast-coverage-audit.md)。
