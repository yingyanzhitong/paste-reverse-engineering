# 离线功能集中检查结论

当前源码版本为0.8.0-dev.35。按完整功能链集中核对，已有满足的代码直接复用，只修证据明确的差异；不按原地址数量重复开发。

## 已修正的主要差异

| 功能链 | 当前修正 | 仍待验收或恢复 |
| --- | --- | --- |
| 多选与粘贴 | 有序Shift分组、独立锚点、点击/菜单选区、复制及数字快贴精确修饰键 | 原生按压/拖动、全部事件与跨应用时序 |
| 删除定位 | 旧选区右邻优先、左邻兜底，按身份在当前集合重找，不强制跳首项 | 原异步applier、确认/权限与错误回调 |
| 来源应用图标与背景色 | 共享图标与rawColor持久化；47应用覆盖、精确像素计数、完整ARGB及Header读取；坏图为空图 | 未知应用占位像素、旧历史缺失owner/来源信息及原生对象 |
| 搜索与整理 | 复用原查询构造、索引及Pinboard显式归属、属性、八色和顺序路径 | 完整原模型、并发/错误与交互回归 |
| 链接卡片 | 原生渐变背景、独立底栏底色、主图自适应缩放、42点图标圆角与偏移 | 原progress转场、文本原生布局及Hosting组合回归 |
| 窗口和卡片 | 失焦收起、关闭中重开、尺寸保存、图片/文件布局修正 | 完整原生生命周期、像素和OS版本矩阵 |
| 历史保留 | 默认30天、按真实动作年龄清理，移除无证据的数量删除 | 原CoreData、Undo和全部触发边界 |

来源图标现已接成实际采集到显示的数据链：同一应用的新采集更新共享记录，旧项目读取新图标而无需修改时间。JSON归档缺新增字段仍兼容；坏图标原始字节不会被静默丢弃。旧记录无法仅凭bundleID还原原来的应用实体或历史图标，因此不伪造该证据。

颜色链路现已接通真实采集、共享记录和Header读取。完整ARGB编码以及原函数固有128目标的图标取色均已绑定完整原体、实际编译入口与独立静态复核；输入图像尺寸未被缩窄。47项常量另有[只读核验报告](source-application-color-table.json)。原工厂在相同图标时跳过取色，而当前快照提前计算，这一时序和性能差异仍保留。

Pinboard现在保存显式owner与原始属性，按原八色随机新建、精确映射颜色，恢复Header的专色和12点圆形路径图标。隐藏应用图标与启用Pinboard专色分别判断；坏属性不会被伪造成有效Pinboard。旧归档缺失关系继续兼容，不从多个归属中随机挑一个。

链接主图已接真实尺寸类别与自适应阈值，Header图标已复用现有重采样函数，详见[图片显示链静态审阅](link-and-header-image-static-audit.json)。已有绘制函数直接复用，没有重新逐函数开发。Link渐变背景、独立底栏底色及42点图标圆角/紧凑偏移也已补齐，见[原生背景静态审阅](link-native-surface-static-audit.json)。下一步核清原生按压/拖拽的完整委托与图标占位；颜色、文件、选择和删除已满足行为直接跳过。

## 验证结果与限制

release编译build60通过，耗时10.68秒，169个输入在编译前后摘要一致。当前源码、生成源码和编译产物摘要见[静态快照](concentrated-static-build60.json)，Pinboard整链及独立交叉核查见[静态审阅](pinboard-header-static-audit.json)。

73项静态行为检查中，32项已有列明行为的代码，39项仍有差异或证据缺口，1项缺实现、1项未完成核对。粒度不同，不能换算产品完成率。完整逐地址证据仍为1499个（源码586、SDK真实转发913）。本轮1条既有源码证据与913条SDK绑定刷新，新增22个SDK候选未计迁移；本轮4个原函数新增partial，不因局部补齐冒充完整迁移。

没有启动应用或执行单元、功能、UI、MCP测试。编译和静态核对不能证明一比一通过；既有NSImage跨actor与NSEvent Sendable风险未在本轮改动。按既定顺序，迁移阶段结束后再统一功能回归。
