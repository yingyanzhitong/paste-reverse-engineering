# 离线功能集中检查结论

当前源码版本为0.8.0-dev.33。按完整功能链集中核对，已有满足的代码直接复用，只修证据明确的差异；不按原地址数量重复开发。

## 已修正的主要差异

| 功能链 | 当前修正 | 仍待验收或恢复 |
| --- | --- | --- |
| 多选与粘贴 | 有序Shift分组、独立锚点、点击/菜单选区、复制及数字快贴精确修饰键 | 原生按压/拖动、全部事件与跨应用时序 |
| 删除定位 | 旧选区右邻优先、左邻兜底，按身份在当前集合重找，不强制跳首项 | 原异步applier、确认/权限与错误回调 |
| 来源应用图标与背景色 | 共享图标与rawColor持久化；47应用覆盖、精确像素计数、完整ARGB及Header读取；坏图为空图 | 未知应用占位像素、旧历史缺失owner/来源信息及原生对象 |
| 搜索与整理 | 复用原查询构造、索引及Pinboard显式归属、属性、八色和顺序路径 | 完整原模型、并发/错误与交互回归 |
| 窗口和卡片 | 失焦收起、关闭中重开、尺寸保存、图片/文件布局修正 | 完整原生生命周期、像素和OS版本矩阵 |
| 历史保留 | 默认30天、按真实动作年龄清理，移除无证据的数量删除 | 原CoreData、Undo和全部触发边界 |

来源图标本轮接成实际采集到显示的完整数据链：同一应用的新采集更新共享记录，旧项目读取新图标而无需修改时间。JSON归档缺新增字段仍兼容；坏图标原始字节不会被静默丢弃。旧记录无法仅凭bundleID还原原来的应用实体或历史图标，因此不伪造该证据。

颜色链路现已接通真实采集、共享记录和Header读取。完整ARGB编码以及原函数固有128目标的图标取色均已绑定完整原体、实际编译入口与独立静态复核；输入图像尺寸未被缩窄。47项常量另有[只读核验报告](source-application-color-table.json)。原工厂在相同图标时跳过取色，而当前快照提前计算，这一时序和性能差异仍保留。

Pinboard现在保存显式owner与原始属性，按原八色随机新建、精确映射颜色，恢复Header的专色和12点圆形路径图标。隐藏应用图标与启用Pinboard专色分别判断；坏属性不会被伪造成有效Pinboard。旧归档缺失关系继续兼容，不从多个归属中随机挑一个。

下一步集中处理三条对外观和交互影响较大的链：链接主图自适应裁切（已确认差异）、原生按压和拖拽事件、Header图标栅格化与未知应用占位。满足的颜色、文件、选择和删除行为直接复用。
